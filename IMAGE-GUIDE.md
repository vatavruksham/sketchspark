# SketchSpark — Image Generation Guide

## Concept
SketchSpark is an AI sketch-to-artwork platform. Images should reflect creative/art themes — sketches, artwork, creative workspaces, art supplies, digital art, canvas paintings.

## Demo Section (SVG Filter Approach)
The AI demo uses **SVG filters** applied to the same source image:
- `#pencil-sketch` filter → grayscale edge-detect (sketch look)
- `#illustration` filter → saturated posterized (finished artwork look)
